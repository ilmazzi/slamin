# ===========================================
# ISTRUZIONI SETUP
# ===========================================

# STRIPE:
# 1. Vai su https://dashboard.stripe.com/
# 2. Crea un account o accedi
# 3. Vai su "Developers" > "API keys"
# 4. Copia "Publishable key" e "Secret key"
# 5. Per i webhook: "Developers" > "Webhooks" > "Add endpoint"
#    URL: https://slamin.local/webhook/stripe
#    Eventi: payment_intent.succeeded, payment_intent.payment_failed

# PAYPAL:
# 1. Vai su https://developer.paypal.com/
# 2. Accedi con il tuo account PayPal
# 3. Vai su "My Apps & Credentials"
# 4. Crea una nuova app o usa quella esistente
# 5. Copia "Client ID" e "Client Secret"
# 6. Modalità: Sandbox per test, Live per produzione
